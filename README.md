# Sangeet Sadhana — KVS Mumbai Region Music Teachers Training 2026

A responsive GitHub Pages information hub for the five-day, face-to-face Mass Saturation Training for Music Teachers of KVS Mumbai Region at ZIET Mumbai, 23–27 November 2026.

## Deploy with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/ (root)**, then Save.
4. Wait for GitHub Pages to publish the site. The URL will be:
   https://taprimaryzietmumbai-kjrd.github.io/KVS-MUMBAI-MUSIC-TEACHERS-TRAINING-2026/

## Current functionality
- Responsive training landing page and navigation.
- Five-day programme placeholders.
- Local participant list with CSV export.
- Addable resource and documentation links.
- Local reflection pad with CSV export.

## Important data note
Participant entries, resource links, documentation links and reflections are stored in the browser's local storage on the device/browser where they are entered. They are **not** synchronised to a central Google Sheet or visible to other participants. Do not use this version for official attendance or confidential records. Add the approved Google Sheets / Apps Script backend before using shared data workflows.
